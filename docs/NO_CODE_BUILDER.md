# No-Code Builder Foundation\n\nThis branch adds an executable first No-Code step: describe a simple product in Uzbek and receive a responsive static web/PWA starter as files.\n\n## API\n\nPOST /api/builder/generate with JSON {task: ...} returns index.html, manifest.webmanifest, and README.md.\n\nThe generator is honest about scope: it does not yet build an APK, connect a database, create accounts/payments, publish a site, or claim a browser/device test passed.\n\n## Design\n\n- No paid model key is required for deterministic starter generation.\n- Output is portable and can be committed to a separate GitHub repository.\n- No server disk is required; generated files are returned in the API response.\n- User input is HTML-escaped; no third-party scripts are injected.\n\n## Next stages\n\n1. Verified isolated build runner.\n2. GitHub project provisioner with scoped permissions.\n3. Static hosting deployment and live URL verification.\n4. Capacitor Android wrapper and APK artifact build.\n5. Model-backed specification and iterative code generation when an inference endpoint is configured.\n6. Durable user/project metadata storage; Render local filesystem is not durable unless a persistent disk is mounted.\n
