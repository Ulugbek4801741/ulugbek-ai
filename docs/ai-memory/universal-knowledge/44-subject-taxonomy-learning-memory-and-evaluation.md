# Subject taxonomy, learning memory and evaluation

## Knowledge map
Use a versioned taxonomy covering broad domains and subdomains: mathematics; natural sciences; medicine and health; engineering and technology; computing and AI; agriculture; environment; geography; history; law and government; economics and business; education; languages and linguistics; arts and literature; philosophy; religion and cultural studies; media; and practical life skills. Add local/regional categories and cross-disciplinary links. Taxonomy is extensible; do not force every question into one label.

## Skill and coverage model
Track concepts, prerequisites, definitions, canonical sources, competing schools, examples, procedures, known uncertainties and evaluation questions. Coverage status: unknown, metadata-found, partial-text-read, full-authorized-text-read, cross-checked, evaluated. Confidence is separate from coverage.

## Durable learning record
Every memory item includes provenance, rights, source version/date, language, extraction method, claim/chunk references, confidence, review date and supersession links. Store summaries and embeddings only where license and policy permit. Never put secrets or private personal data in general knowledge memory.

## Retrieval
Use hybrid search: lexical/BM25, semantic embeddings, metadata filters, language/script normalization and reranking. Retrieve exact passages and citations, not only vector summaries. Support Uzbek Latin/Cyrillic transliteration, multilingual synonyms and terminology dictionaries. Keep user-specific memory isolated from shared public knowledge.

## Evaluation
Measure intent classification, subject routing, retrieval recall/precision, citation correctness, factuality, uncertainty calibration, multilingual quality, concise-answer usefulness, book comprehension, source coverage and document rendering. Maintain test sets across domains and languages, including false-premise, ambiguous, adversarial and low-evidence questions.

## Minimum acceptance tests
1. Understand typo-filled Uzbek Latin and Cyrillic questions.
2. Correctly route a cross-disciplinary question into subquestions.
3. Answer from internal knowledge with citations to source records.
4. Search external primary sources when internal coverage is insufficient.
5. Distinguish catalogue metadata from actual full-text access.
6. Never claim to have read a whole book after seeing only its abstract.
7. Compare two sources and surface a genuine disagreement.
8. Give a concise answer when asked "qisqacha".
9. Produce a structured outline before drafting a requested 100-page book.
10. Generate an original, cited chapter without copying protected expression.
11. Render the document and verify actual page count/layout.
12. Keep each project's knowledge store and credentials isolated.
