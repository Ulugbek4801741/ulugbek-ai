# Search and Open Data Source Catalog

Prefer these source classes and verify their current terms before use:
- Official government open-data portals and public statistics.
- Standards bodies and official technical documentation.
- Universities, institutional repositories and open-access journals.
- NASA and other official scientific data APIs.
- Wikidata and other knowledge graphs under their published terms.
- Common Crawl public web archive datasets under Common Crawl terms.
- Public code repositories with explicit open-source licenses.
- Official RSS/Atom feeds and publisher APIs.

Do not treat this list as blanket permission to scrape every linked domain. Register each source's API endpoint, license, rate limit, robots policy, authentication need, allowed use and last verification date before automated collection.
