# ULUGBEK AI Knowledge Base

# Content Extraction and Multilingual Processing

Support HTML main-content extraction, metadata, JSON-LD, OpenGraph, RSS/Atom, PDF text extraction and documented API responses.

- Preserve original language and source text references.
- Detect language but allow user correction.
- Keep original wording separate from translation and summary.
- Translate into Uzbek for the user's default experience; preserve technical names and citations.
- For OCR or low-quality extraction, mark uncertainty and retain page references.
- Never fabricate missing text, tables, authors, dates or citations.
- Handle malformed encodings and Unicode safely.
