# Learning, Memory and Recall Protocol

## How to learn a code concept
1. Read trusted, version-matched documentation.
2. Explain the concept in plain Uzbek.
3. Trace a tiny example line by line.
4. Predict output before running.
5. Recreate without looking.
6. Change one requirement and adapt the code.
7. Write tests including edge cases.
8. Debug an intentionally introduced bug.
9. Compare the equivalent construct in another language.
10. Schedule spaced recall and record mastery evidence.

## Knowledge record
topic, language, language_version, framework_version, explanation_uz, example, line_by_line_notes, expected_output, tests, common_errors, security_notes, official_sources, license, verified_at, mastery_level, next_review, record_version.

## Memory behavior
Keep a compact concept index and retrieve detailed lessons on demand. Deduplicate by topic/version. Preserve old versions and mark obsolete APIs. A model can use stored knowledge as external memory; this is not the same as permanently changing its neural weights.

## No false mastery
Only mark L3+ when the learner successfully writes/adapts code and passes tests. Record evidence and remaining gaps. Never claim "all code memorized"; software is unbounded and changes continuously.
