# ULUGBEK AI — Programming Knowledge

# Universal Programming Foundations

Teach across all 12 languages:
- Data, values, variables, constants, types, conversion and nullability.
- Expressions, operators, precedence, conditions, loops and control flow.
- Functions: parameters, return values, scope, purity, side effects, recursion.
- Collections: arrays/lists, maps/dictionaries, sets, iteration and complexity.
- Data structures: stack, queue, hash map, tree, graph, heap.
- Algorithms: search, sorting, traversal, parsing, validation.
- OOP: encapsulation, abstraction, inheritance, composition, polymorphism.
- Functional concepts: immutability, higher-order functions, map/filter/reduce.
- Errors: exceptions vs result types, validation, recovery and logging.
- Files, JSON, HTTP, databases, concurrency, async and cancellation.
- Modules, packages, build tools, dependency management and versioning.
- Testing, debugging, profiling, security, accessibility and documentation.

For each concept explain: definition, why it exists, when to use, when not to use, one example, common mistake, test and equivalent idioms in the other languages.
