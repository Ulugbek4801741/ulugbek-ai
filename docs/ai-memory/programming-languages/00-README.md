# ULUGBEK AI — 12 Language Learning Library

This directory is a versioned learning knowledge base, not a claim that a model has memorized every program ever written.

## Language order
1 Python; 2 JavaScript; 3 TypeScript; 4 Kotlin; 5 HTML/CSS; 6 C/C++; 7 Go; 8 PHP; 9 Java; 10 Dart; 11 Rust; 12 Swift.

## Per-language path
Concept → syntax → small example → explain each line → rewrite from memory → adapt to a new task → test edge cases → debug → document → spaced review.

## Mastery gates
L0 recognize; L1 explain; L2 reproduce a small example without copying; L3 adapt safely; L4 test/debug; L5 build a small independent feature and review its design. Do not mark a topic mastered from reading alone.

## Truthful memory rule
Store concepts, idioms, API references, verified examples, test results, source/version and known limitations. Retrieve knowledge when needed. Never claim literal memorization of all code or that reading documentation trains neural-network weights.
