Windows virtual kompyuter

Bu qismni haqiqiy ishlatish uchun bulutli VM, litsenziya, masofaviy ish stoli gateway va foydalanuvchi autentifikatsiyasi kerak.

Server hali ulanmagan

Hozirgi loyihada Windows virtual mashinasini yaratish, ishga tushirish yoki 10–100 ta dasturni bir vaqtda bajarish xizmati sozlanmagan. Bu sahifa Windows ishlayapti deb ko‘rsatmaydi. Server provayderi va budjet belgilangach, alohida xavfsiz VM boshqaruvi qo‘shiladi.

Imkoniyatlar va cheklovlar

  • Android: Google Play orqali mos ilovani tanlash.
  • Windows: alohida Windows kompyuter yoki litsenziyalangan bulutli VM talab etiladi.
  • iPhone: App Store ilovalari Apple qurilmasida o‘rnatiladi; Androidda iOS ilovasi sifatida ishlamaydi.
  • 10–100 ta ilova: VM resurslari va ilova litsenziyalariga bog‘liq; bu son hozircha kafolatlanmaydi.
  • Xavfsizlik: ilovalarni yashirin yuklab olish, o‘rnatish yoki telefon ruxsatlarini avtomatik berish yo‘q.
