## Operating rule
Use these documents as the project's intended policy and retrieval knowledge. They are not proof that a feature is implemented. Before claiming a capability, inspect the source code, tests, configuration and live health checks.

## Memory lifecycle
Collect → validate source → extract → deduplicate → classify → store with provenance → retrieve → answer/act → evaluate → revise with version history.
